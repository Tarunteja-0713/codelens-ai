CodeLens AI — Multi-Language Static Code Review Assistant

Designed as an educational developer-tool utility for fast, deterministic, offline static source analysis and AI-style remediation guidance.

Key Features

  • Multi-Language Ingestion (.py, .js, .sql, .html, .css, .java, .cs, .c, .cpp)
  • Pure client-side ZIP archive unpacker
  • Offline, deterministic rule-based AI explanation generation
  • Exportable audit reports in structured JSON and print-ready HTML
  • Interactive health score heuristic calculator (0-100)

Security & Sandboxing

Source code uploaded to CodeLens AI is strictly parsed as immutable UTF-8 string tokens. It is never evaluated, compiled, or executed via eval(), nor transmitted across any external network interface.
